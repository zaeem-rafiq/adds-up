# Screen designs

These 32 pictures are the design of Adds Up: 16 screens, each at desktop and phone width. They were drawn on November 20, 2026, the day before the hackathon, as planning.

They are pictures only. The product's code, markup and style were written at the Gemini 4 NYC Hackathon on November 21, 2026, after hacking began at 10:30 AM ET. The first commit also holds scaffold and template files. The main README lists them.

Some words on the live screens differ from the pictures. The list below holds the differences that are known. The live page is the current version.

- **Results screen:** the three rows for the second reader read "The second reader agrees", "The second reader is unsure" and "The second reader disagrees". The pictures read "Tick", "Ask you" and "Not proven".
- **Note on a gap:** the note is headed "Carbon's note". The pictures say "Neon's note". Carbon took that job.
- **Upload screens:** the pictures show a PDF file and say "Drop a PDF page or a picture here". The live screen asks for a picture, PNG or JPEG. A PDF is refused.
- **Within rounding:** this third mark is in no picture. It shows as an amber check on a dashed ring, with a note such as "Adds up within rounding, off by 1".
